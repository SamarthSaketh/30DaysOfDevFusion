
# 💸 Day 11 Expense Tracker

## 📝 Description

A powerful and interactive **Expense Tracker Web App** built using **HTML, CSS, JavaScript, and Chart.js**. It helps users efficiently manage their daily finances with real-time tracking, filtering, and data visualization. All data is stored in the browser using `localStorage`, ensuring quick access and offline capability.

---

## 🚀 Features

- 🧾 Add new transactions with info, amount, and date  
- 🔍 Search, filter by **month**, **year**, or **custom date range**  
- 🗂️ Categorized receipt/payment entries  
- 💰 Running balance with real-time updates  
- 🧹 Reset filters, sort by date, and clear data  
- 📤 Export data to **Excel (XLSX)** format  
- 🧮 Opening balance support  
- 🔍 Live search functionality  
- ♻️ Delete individual entries  
- 📅 Auto-generates year options dynamically  
- 🖱️ Resizable columns for better UX

---

## 💻 Tech Stack

- **HTML5 + CSS3 (Flexbox/Grid)**  
- **Vanilla JavaScript**  
- **SheetJS (xlsx)** – Export to Excel  
- **localStorage API** – Persistent data  
- **Bootstrap Icons** (optional)

---

## ⚙️ How to Run

1. Clone or download this repository.

2. Open `index.html` in any modern browser (Chrome, Firefox, Edge).

> ✅ No setup or installation required. It's a fully client-side app!
