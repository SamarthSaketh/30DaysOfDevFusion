# 📅 Day 2 – Smart Age Tracker

## 📝 Description
This project is a **Smart Age Tracker** that calculates your **exact age** in years, months, and days, shows the **total time lived**, and displays a **live countdown** to your next birthday.  
It also fetches a fun **historical fact** from Wikipedia based on your birthdate to make it more engaging!

---

## 🚀 Features

- 🎯 Calculates accurate age (years, months, days)
- ⏳ Shows total time lived (days, weeks, hours, minutes, seconds)
- 🧭 Live second counter that updates in real-time
- 🎉 Countdown timer until next birthday with flip animation
- 🧠 Displays a random "On This Day" fact from Wikipedia
- 💡 Clean and responsive card-based UI

---

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Wikipedia REST API

---

## 📂 How It Works

1. Enter your **date of birth** in the input field.
2. The app calculates your age and time lived.
3. A **live countdown** starts showing how long until your next birthday.
4. A **fun fact** is fetched based on your birthday (month & day).

---

## ⚙️ Setup & Usage

1. Clone or download the repo.
2. Navigate to the `Day2` folder.
3. Open `index.html` in any modern browser.
