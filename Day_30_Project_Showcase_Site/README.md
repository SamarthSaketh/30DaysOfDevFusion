# 📌 Day 30 – DevFusion 30 Projects Showcase

## 📝 Description
This is the **final showcase of the 30 Days of DevFusion challenge**, featuring **all 30 projects** built throughout the challenge.  
The app and this document highlight the **project titles, descriptions, tech stack, and demo links**, giving a complete overview of the coding journey.

## 🛠️ Tech Stack
- **Frontend:** React, Mantine, CSS  
- **Features:** Project CRUD, Calendar Picker, Rich Text Editor, Notifications  
- **Additional Tools:** Axios, Day.js, React-Quill, Tailwind, Bootstrap

## 🚀 How to Run
1. Clone the repo  
```bash
git clone https://github.com/SamarthSaketh/30DaysOfDevFusion.git
````

2. Navigate to the project folder

```bash
cd Day_30_Project_Showcase_Site
```

3. Install dependencies

```bash
npm install
```

4. Run the app

```bash
npm start
```
