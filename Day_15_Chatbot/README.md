# 💬 Day 15 –  Chatbot

## 🤖 Description

An interactive and visually appealing **Chatbot** powered by **Gemini Pro API** and built using **HTML, CSS, and JavaScript (Frontend)** with **Python Flask (Backend)**. It supports smooth typing animations, code block formatting, model switching (Gemini 1.5 Pro / Gemini 1.0), and neatly structured chat bubbles for each conversation — offering a sleek user experience for natural language conversations.

---

## 🚀 Features

* ✍️ Line-by-line typing animation for bot responses
* 📦 Structured chat UI with separate boxes for each question and answer
* 📋 Code block formatting with copy-to-clipboard support
* 🔄 Model selector: Gemini 1.0 / Gemini 1.5 Pro
* 💬 User and Bot messages styled distinctly
* 🌐 Backend API integration using Flask
* 🧠 Natural responses using Gemini Pro via Google AI API

---

## 💻 Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Python Flask
* **API:** Gemini Pro (Google AI)
* **Icons:** Font Awesome (for copy button)
* **Lib:** Prism.js or Highlight.js (for syntax highlighting)

---

## ⚙️ How to Run

1. Clone the repository:
```bash
git clone https://github.com/SamarthSaketh/30DaysOfDevFusion.git
````

2. Navigate to the project folder:

```bash
cd Day_15_Chatbot
```

3. Set up Python environment and install dependencies:

```bash
pip install -r requirements.txt
```

4. Create & add your Gemini API Key in a `.env` file:

```
GEMINI_API_KEY=your-api-key-here
```

5. Start the Flask server:

```bash
python app.py
```

6. Open `http://localhost:5000` in your browser and start chatting!
