

# 🖼️ Day 12 – Grouped Image Gallery

## 📝 Description

A beautifully designed and **fully offline-supported Grouped Image Gallery** built with **HTML, CSS, JavaScript, and IndexedDB**. This interactive app allows users to create image groups, add high-resolution images, and display them using customizable layouts — all while storing data persistently using IndexedDB. It’s a perfect blend of UI interactivity and local storage capability.

---

## 🚀 Features

* 📁 Create, rename, and delete image groups
* 🖼️ Upload and manage high-resolution images in groups
* 🧱 Choose from 5 layout styles: masonry, grid, columns, circle, and carousel
* 💾 Persistent storage using **IndexedDB** (images and metadata retained across reloads)
* 🔍 Full-screen modal image viewer with click-to-close support

---

## 💻 Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**
* **IndexedDB (for local persistent storage)**
* **[Swiper.js](https://swiperjs.com/)** (for carousel layout)
* **Flexbox & Grid** for layout rendering

---

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/SamarthSaketh/30DaysOfDevFusion.git
```

2. Navigate to the project directory:

```bash
cd Day_13_Image_Gallery
```

3. Open `index.html` in your preferred browser:

```bash
Start the app by simply opening index.html
```

✅ No server or build step required — everything runs in-browser.
