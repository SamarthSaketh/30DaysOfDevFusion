# 📌 Day 28 – Keyboard Typing Test

## 📝 Description
An **interactive Typing Test App** built with **React** to improve typing speed, accuracy, and focus.  
It features **multiple difficulty levels (Easy, Medium, Hard)**, along with **Tricky Spellings** and **Story Mode** (50+ lines).  
The app includes a **real-time progress bar, stats tracking, infinite text streaming, and dark/light mode** for a smooth user experience.  

## 🛠️ Tech Stack
- **Frontend:** React, CSS  
- **Features:** Dynamic text generation, difficulty modes, progress bar, dark/light theme  

## ✨ Features
- ⏱️ Adjustable **timer durations** (30s, 60s, 120s)  
- 🎚️ **Difficulty Levels** – Easy, Medium, Hard, Tricky Spelling, Story Mode  
- 📊 Real-time **WPM, Accuracy & Error tracking**  
- 🌗 **Dark/Light mode toggle**  
- 📖 Story Mode with **long-form text (50+ lines)**  
- 🔄 **Infinite text streaming** for continuous practice  

## 🚀 How to Run
1. Clone the repo  
```bash
   git clone https://github.com/SamarthSaketh/30DaysOfDevFusion.git
````

2. Navigate to project folder

```bash
   cd Day_28_Keyboard_Typing_Test
```
3. Install dependencies

```bash
   npm install
```
4. Run the app

```bash
   npm start
```
