# 🧠 Day 18 – Quiz App

## 📝 Description

A fully functional and interactive **Quiz App** built using **HTML, CSS, and JavaScript**. This web-based application allows users to test their knowledge in various categories like **HTML, CSS, JavaScript, Aptitude, Computers, and General Knowledge**. Designed with user experience in mind, the app presents a clean UI, timed quizzes, and accurate scoring mechanics.

---

## 🚀 Features

- 🎯 Choose from multiple quiz categories  
- 🧩 5-question quizzes: Easy to Advanced difficulty  
- ✅ Instant feedback on correct/wrong answers  
- 🔄 Restart quiz functionality  
- 💯 Final score displayed upon completion  
- 🎨 Clean and modern UI (updated from default look)

---

## 💻 Tech Stack

- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla)**  

---

## ⚙️ How to Run

1. Download or clone the project  
2. Place all quiz JSON files in the `quiz_categories/` folder  
3. Open `index.html` in your browser  
4. Select a category and begin the quiz!
