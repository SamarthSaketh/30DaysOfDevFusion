# 🔐 Day 17 – Password Manager 

## 📝 Description

A powerful and user-friendly **Password Manager** built using **HTML, CSS, and JavaScript**. Instantly create strong, secure passwords with customizable options like length, uppercase, lowercase, numbers, and special characters. Includes built-in password strength validation and clipboard copy functionality — ideal for developers, security-conscious users, and everyday productivity.

---

## 🚀 Features

- 🔐 Generate strong, random passwords  
- ✍️ Customizable character options (uppercase, lowercase, numbers, symbols)  
- 👁️ Toggle password visibility  
- 📜 Password rules toggle (hidden by default)  
- 🧹 Clear/reset form easily  
- 🌗 Dark Mode Ready (optional to integrate)

---

## 💻 Tech Stack

- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla)**  

---

## ⚙️ How to Run

1. Download or clone the project  
2. Open `index.html` in your browser  
3. Start generating secure passwords instantly!

---

## 📁 Project Structure

```

Day\_17\_Password\_Generator/
├── index.html       # UI structure
├── style.css        # Styling and optional dark mode
```
