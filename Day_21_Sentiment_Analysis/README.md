# 📌 Day 21 – Sentiment Analysis


## 📖 Description
A Flask-based Sentiment Analysis web app that classifies text as **Positive**, **Negative** using Natural Language Processing (NLP) with **Scikit-learn** and **NLTK**.  
The app features a simple and clean UI where users can input text and instantly receive the sentiment classification with confidence scores.

## 🛠️ Tech Stack
- **Python**
- **Flask**
- **NLTK**
- **Scikit-learn**
- **HTML/CSS**

## 🚀 Features
- 📝 Text input via a browser form
- 📊 Classification into Positive, Negative
- 📈 Confidence score display
- ⚡ Real-time prediction after submission
- 🎯 Balanced training dataset with all 2 sentiment types
- 🔍 Improved preprocessing with stopword removal, bigrams, and negation handling


## 📂 How to Run
1. Clone the repository:
```bash
   git clone https://github.com/SamarthSaketh/30DaysOfDevFusion.git
   cd Day_21_Sentiment_Analysis
````

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
3. Train the model:

   ```bash
   python train_model.py
   ```
4. Start the Flask server:

   ```bash
   python app.py
   ```
5. Open the app in your browser:

   ```
   http://127.0.0.1:5000/
   ```
