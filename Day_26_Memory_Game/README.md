# 📌 Day 26 – Memory Card Game

## 📖 Description

A **Memory Card Game** built with **HTML, CSS & JavaScript**. Match tech icons like HTML, CSS, JS, React, Node.js, and MongoDB. Features **difficulty levels**, **timer**, **move counter**, **shuffle**, and **show-all preview**.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Icons:** Devicon

## 🚀 Features

* 🎮 Flip cards to find pairs
* ⚡ Difficulty: Easy (4 pairs), Medium (8), Hard (12)
* ⏱️ Track time & moves
* 🔀 Shuffle & 👀 Show All Cards
* ✅ Win by matching all pairs

## 📂 How to Run

Open `index.html` in a browser and start playing. No backend required.
