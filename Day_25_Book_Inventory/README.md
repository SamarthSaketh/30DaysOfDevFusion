# 📌 Day 25 – Book Inventory Management System

## 📖 Description

A **Book Inventory** web application built with **React**, **Material-UI**, and **Node.js/Express/MongoDB**.
The app allows users to **add, edit, delete, view, and download books**, including **PDF uploads**. It features a **dynamic filter system** and a **modern, responsive UI** with toast notifications for smooth user interaction.

## 🛠️ Tech Stack

* **Frontend:** React, Material-UI
* **Backend:** Node.js, Express
* **Database:** MongoDB
* **File Upload:** Multer
* **Notifications:** react-toastify

## 🚀 Features

* ➕ **Add New Books:** Upload book details with optional PDF attachment.
* ✏️ **Edit Books:** Update book information and replace PDFs.
* 🗑️ **Delete Books:** Delete books with confirmation via toast notification.
* 👁️ **View PDFs:** Preview uploaded PDFs directly in the browser.
* ⬇️ **Download PDFs:** Download book PDFs with correct filenames.
* 🎨 **Filter System:** Filter books by Author, Genre, and Year.
* ⚡ **Dynamic UI:** Modern card layout with genre-based color coding and responsive design.
* 🔔 **Toast Notifications:** Visual feedback for add, edit, delete, and error events.

## 📂 How to Run

### Backend

1. Navigate to the backend folder.
2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file with your MongoDB URI:

```env
MONGO_URI=your_mongodb_connection_string
```

4. Start the server:

```bash
node server.js
```

### Frontend

1. Navigate to the frontend folder.
2. Install dependencies:

```bash
npm install
```

3. Start the React app:

```bash
npm start
```

4. Open `http://localhost:3000` in your browser.
