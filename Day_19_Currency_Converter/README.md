

# 💱 Day 19 – Currency Converter

## 💡 Description

A simple and clean **Currency Converter** built using **HTML, CSS, and JavaScript**. It allows users to convert between currencies with real-time exchange rates and displays country flags.

---

## 🚀 Features

* 🔄 Currency conversion between any two currencies
* 🌍 Real-time exchange rates using API
* 🏳️ Country flags auto-update on selection
* 📱 Fully responsive design

---

## 🛠️ Tech Stack

* HTML, CSS, JavaScript
* Font Awesome, Google Fonts
* [ExchangeRate API](https://www.exchangerate-api.com/) (or similar)

---

## ⚙️ How to Run

1. Clone or download the repository
2. Open the folder in **VS Code**
3. Run `index.html` in your browser (just double-click or use Live Server)

---

## 📁 Project Structure

```
Day_19_Currency_Converter/
├── index.html       # Main HTML layout
├── style.css        # Styling for the converter
├── script.js        # Logic for conversion & API calls
└── country-list.js  # Currency codes with country flag data
```
