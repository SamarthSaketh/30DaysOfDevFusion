

# 🧠 E-commerce Product Page

## 📝 Description

A simple **E-commerce Product Page** built using **React** and **React-Bootstrap**. The app supports adding/removing products from cart, updating quantities, and a checkout form collecting shipping and payment details. Includes a simulated payment processing with a loading spinner and success confirmation. Cart can be cleared manually or after order placement. Navigation to Home is provided.

---

## 🚀 Features

 🛒 Add/remove products with quantity controls
 📦 View cart items with subtotal and total price
 🧾 Checkout form collecting shipping & payment details
 ✅ Displays order confirmation and clears cart after purchase

---

## 💻 Tech Stack

* **React**
* **React-Bootstrap**
* **React Router**

---

## ⚙️ How to Run

1. Clone or download the React project
2. Install dependencies with `npm install` or `yarn`
3. Run with `npm start` or `yarn start`
4. Use the app in the browser, add products, and proceed to checkout
