## 📌 Day 22 – Tic-Tac-Toe Game with AI


## 📖 Description

A Tic-Tac-Toe web game built with **HTML**, **CSS**, and **JavaScript**. The app features two modes: a classic Player vs. Player mode and a challenging Player vs. Computer mode with an unbeatable AI powered by the **Minimax algorithm**. The user interface includes a dynamic theme switcher with a futuristic AI activation animation.

## 🛠️ Tech Stack

  - **HTML/CSS**
  - **JavaScript**
  - **anime.js** (for animations)

## 🚀 Features

  - 👥 **Player vs. Player (PvP) Mode:** A classic two-player game experience.
  - 🤖 **Player vs. Computer (PvC) Mode:** An unbeatable AI opponent using the **Minimax algorithm**.
  - 🎨 **Dynamic Theme Switching:** A clean, elegant theme for PvP and a futuristic, "glitchy" theme for PvC.
  - 🎬 **Computer Activation Animation:** A full-screen animation with flying shapes and glitching text when switching to computer mode.
  - ⌨️ **Keyboard Shortcuts:** Use 'C' to toggle modes and 'R' to restart the current game.
  - 📱 **Responsive Design:** The game board and UI adapt to different screen sizes.

## 📂 How to Run

1.  Save the three files (`index.html`, `style.css`, `script.js`) into the same directory.
2.  Open the `index.html` file in your web browser.
