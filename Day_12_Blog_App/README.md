# 📝 Day 12 – Blog API

## 📝 Description

A powerful and scalable **Blog API** built with **Node.js, Express, and MongoDB**. This RESTful backend allows users to perform full CRUD operations on blog posts and manage users securely. Designed with modular routes and clean architecture, it serves as a solid foundation for any full-stack blog platform.

---

## 🚀 Features

- 📬 Create, Read, Update, and Delete blog posts  
- 🧱 RESTful API structure using Express routing  
- 🛡️ Input validation and error handling  
- 🗂️ Organized code with modular route handling  
- 📦 MongoDB for data persistence with Mongoose ODM

---

## 💻 Tech Stack

- **Node.js (v18+)**  
- **Express.js**  
- **MongoDB + Mongoose**  
- **Postman (for API testing)**  
- **dotenv**  
- **Nodemon (for development)**

---

## ⚙️ How to Run

1. Clone the repository

2. Navigate to the project folder:

```

cd Day\_12\_Blog\_API

```

3. Install dependencies:

```

npm install

```

4. Add your MongoDB URI in db.js:

```

MONGODB\_URI=your\_connection\_string

```

5. Run the app:

```

npm run dev

```

6. Use Postman or any API client to test endpoints like:

- `GET /api/posts`
- `POST /api/posts`
- `PUT /api/posts/:id`
- `DELETE /api/posts/:id`
