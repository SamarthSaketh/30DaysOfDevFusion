# 📌 Day 27 – Pokémon Battle Simulator

## 📖 Description

A **Pokémon Battle Simulator** built with **React** and **Chakra UI**. Choose your favorite trainers, select a team of 3 Pokémon each, and battle in turn-based fights. Features **stats-based battles**, **animations**, **strength bars**, and **winner detection**.

## 🛠️ Tech Stack

* **Frontend:** React, Chakra UI, Framer Motion
* **Animations:** Framer Motion
* **Data Source:** [PokéAPI](https://pokeapi.co/)

## 🚀 Features

* ⚔️ Select trainers for both teams  
* 🐱‍👤 Choose up to 3 Pokémon per team  
* 📊 Pokémon stats: Attack, Defense, Speed  
* 🎮 Turn-based battle simulation with animations  
* 📈 Strength bar visual for Pokémon  
* 🎉 Confetti celebration for the winning team  
* 🔄 Reset and start a new game  

## 📂 How to Run

1. Clone the repository:  
```bash
   git clone https://github.com/SamarthSaketh/30DaysOfDevFusion.git
````

2. Navigate to the project folder:

```bash
   cd pokemon-battle
```
3. Install dependencies:

```bash
   npm install
 ```
4. Start the app:

```bash
   npm start
```
5. Open `http://localhost:3000` in a browser.
