# 🧮 Day 14 – Scientific Calculator

## 🧮 Description

A dynamic and fully responsive **Scientific Calculator Web App** built using **HTML, CSS, and JavaScript**. It supports both basic and scientific operations with a seamless mode toggle, keyboard input, and a modern UI featuring light/dark theme support. Perfect for quick calculations or advanced math on any device – no backend required.

---

## 🚀 Features

* 🧠 Basic + Scientific mode toggle
* ➕ Perform all standard operations: +, –, ×, ÷
* 📐 Scientific functions: sin, cos, tan, log, ln, √, π, e, factorial, exponentiation
* 📜 Calculation history with toggle view
* 🌗 Light/Dark theme switch
* ⌨️ Full keyboard input support
* 🔤 Keyboard shortcuts with shortcut help popup
* 📱 Fully responsive & mobile-friendly design

---

## 💻 Tech Stack

* **HTML5**
* **CSS3**
* **Vanilla JavaScript**
* **Font Awesome** (for icons)

---

## ⚙️ How to Run

1. Clone the repository:

```
   git clone https://github.com/SamarthSaketh/30DaysOfDevFusion.git
```

2. Open the project folder in your code editor or just double-click the `index.html` file to launch in browser:

```
   cd Day_14_Scientific_Calculator
```

3. Start calculating offline — no build or server setup needed!
