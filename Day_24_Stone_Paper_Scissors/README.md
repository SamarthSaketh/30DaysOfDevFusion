

#  Stone Paper Scissors

## 📝 Description

A fun and interactive **Stone Paper Scissors** game built with **HTML, CSS, and JavaScript**.
Players compete against the computer, with the result of each round displayed instantly. Includes a score counter and a reset button.

---

## 🚀 Features

* 🎮 Play against the computer
* 🖼️ Uses custom stone, paper, and scissors icons
* 📊 Real-time score tracking
* 🔄 Reset button to start fresh

---

## 💻 Tech Stack

* **HTML**
* **CSS**
* **JavaScript**

---

## ⚙️ How to Run

1. Download or clone the project folder
2. Open `index.html` in any browser
3. Start playing!
