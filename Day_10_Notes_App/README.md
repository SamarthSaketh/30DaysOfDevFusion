# 📝 Day 10 – Notes App

## 📝 Description

A clean and responsive **Notes App** built with **.NET and Blazor WebAssembly**. It allows users to add, view, and delete personal notes — all saved to local storage for persistence. With a modern UI, this app is lightweight, fast, and works entirely on the browser without any backend.

---

## 🚀 Features

- ✍️ Add & view multiple notes  
- 🗑️ Delete notes anytime  
- 💾 Data stored in browser's localStorage  
- 📱 Fully responsive and mobile-friendly  
- ⚙️ Blazor WebAssembly – no server needed

---

## 💻 Tech Stack

- **.NET 7+**  
- **Blazor WebAssembly (WASM)**  
- **Bootstrap 5**  
- **JavaScript (for localStorage – via JSInterop)**

---

## ⚙️ How to Run

1. Clone the repository:  
```
   git clone https://github.com/your-username/Day_10_Notes_App.git
````

2. Navigate to the project folder:

```
   cd Day_10_Notes_App
```
3. Run the app:

```
   dotnet run
```
4. Open your browser and visit:
   [https://localhost:5001](https://localhost:5001)
